# My Portfolio

## Site URL: 
https://cornerstonee3.github.io/iwamad-sis1-portfolio/

## Description: 
This is a single-page website with my personal portfolio. It contains 3 of my projects with links and short descriptions and a form to contact me and you can toggle dark and white themes. The website is built with HTML, CSS, Javascript.

## Design
1. **Fonts:** I decided to use different font type and found one on GoogleFonts. The reason is I wanted to make my site a little bit unique.
2. **Project Cards Interactions:** I added a hover effects to the project cards, including a slight vertical lift and deeper shadows (`hover:-translate-y-1 hover:shadow-lg`). This makes the website feel more interactive and apealling to eyes.
3. **Spacing:** I decided to use highly spacios design using large vertical padding, huge circular profile image. This attracts attention and draws focus to content.
